# 파크골프친구 체험판

구장에서 만나 같이 치고, 친구가 되는 파크골프 — 체험판입니다.

**https://goingoingon2.github.io/parkfriend/**

- 서버 없이 돌아가는 단일 HTML(`index.html`)입니다. 예시 데이터로 움직이고, 입력한 내용은 그 기기에만 남습니다.
- 첫 화면에서 아무것도 적지 않고 [로그인]을 누르면 예시 계정으로 들어갑니다.
- 소스는 비공개 저장소(golfmemo)의 `golfmemo/parkfriend/` 에 있고, 이 파일은 거기서 `npm run build:demo` 로 만든 결과를 복사한 것입니다.
